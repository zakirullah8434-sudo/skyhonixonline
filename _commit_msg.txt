perf(cold-start): skip main.db migration when app_meta schema marker matches

initMainDbTurso() ran ~30 sequential Turso round trips (tables + the
school-tenant table set) on every serverless cold start, which is where the
~10s first request came from. app_meta.schema_version now records a completed
migration so a cold start finishes in a single round trip.

- main_db_init.js: MAIN_SCHEMA_VERSION marker helpers for both the Turso and
  local sqlite paths; initSchoolTablesTurso reports errors so the marker is
  only written when every table was created
- local main.db gains the app_meta marker row

Bump MAIN_SCHEMA_VERSION whenever initMainDb/initMainDbTurso/
initSchoolTablesTurso changes.
