Core Management Modules

SkyHonix provides a comprehensive set of web modules tailored to match real school administration workflows.

👥

Student Management

Track detailed student records, generate unique student card IDs, upload photos, and link siblings together for unified family accounts.

📷

QR Webcam Attendance

Mark attendance by class/section, view chronological histories, and scan students' ID cards directly in the browser using any standard webcam.

💰

Carry-Forward Fees

Automatically calculate sibling fee exemptions (free/discount settings) and carry forward outstanding dues into next month's ledger.

📊

Exam Grading & DMC

Define term subjects, input marks via editable spreadsheets, compute dense rankings, and export professional Detailed Marks Certificates.
